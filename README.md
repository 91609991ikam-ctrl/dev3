# 🚶 さんぽビンゴ

散歩を少しだけ楽しくするための、3×3 のビンゴアプリ。

毎週月曜に **9つのゆるいミッション** が届きます。「黄色い食べもの」「自分の影」「はじめて通る道」くらいの、
歩いていれば数分で見つかる難易度です。見つけたら写真を撮ってマスに紐づけるとクリア。
タテ・ヨコ・ナナメが揃うとビンゴになります。

## できること

- **毎週9マスの自動更新** — 週番号から決まるので、月曜になると勝手に新しいカードになる
- **写真でクリア** — その場でカメラ、または保存済みの写真から選ぶ
- **ビンゴ判定** — 8ライン。揃うとお祝いが出て、そのラインが金色になる
- **引き直し** — どうしても無理なミッションは、週に1回だけ引き直せる
- **アルバム** — 過去の週も含めて、撮った写真を振り返れる
- **完全オフライン** — 写真も進捗も端末内（IndexedDB）だけ。サーバーもアカウントも不要
- **ホーム画面に追加**（PWA）して、電波のない場所でも使える

## ミッションのバリエーション

16カテゴリ × 12個 = **192ミッション**。

いろ / かたち / いきもの / しょくぶつ / そら・てんき / まちかど / もじ・すうじ / のりもの /
ひかりとかげ / ちいさな発見 / くらしのあと / たべもの / おと・かおり / うごき / なつかしい / すきま・きわ

抽選は次のようになっています。

- 毎週、**9つの違うカテゴリ**から1つずつ引く（同じジャンルが2マス並ばない）
- カテゴリごとに「シャッフルした山札を1枚ずつめくる」方式なので、同じミッションは
  山札を一周するまで戻ってこない（実測で再登場は最短4週・中央値17週）
- 週番号だけから決まるので、同じ週なら誰の端末でも同じカードになる

## 使いかた

そのまま `index.html` を開くだけでも動きますが、Service Worker（オフライン対応）を有効にするには
HTTP で配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000 をスマホのブラウザで開く
```

GitHub Pages などの静的ホスティングにそのまま置けます（ビルド不要・依存パッケージなし）。
スマホで開いたら「ホーム画面に追加」しておくとアプリのように使えます。

## テスト

```sh
node test/board.test.js   # 400週ぶんの抽選を検証（重複なし・全ミッション登場・再現性）
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目（ライト/ダークモード対応） |
| `missions.js` | ミッションのプール（ここを編集すれば自由に増やせる） |
| `store.js` | IndexedDB への保存（写真・週ごとの状態） |
| `app.js` | 週の計算、抽選、ビンゴ判定、画面の描画 |
| `sw.js` / `manifest.json` / `icon.svg` | PWA まわり |

## ミッションを増やす

`missions.js` の配列に足すだけです。1カテゴリの件数を変えても抽選はそのまま動きます。

```js
{ t: 'マスに出す短い名前', h: 'タップしたときに出るゆるいヒント' }
```
